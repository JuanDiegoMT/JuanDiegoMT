### 🌱 Plant Health RAG System

Built an end-to-end **Retrieval-Augmented Generation system** focused on plant health and pest management.

The system is designed to help analyze plant-related information and provide context-aware answers regarding:

- 🐛 Pest identification
- 🌿 Affected plant species
- 📊 Infestation assessment
- 🔎 Plant damage analysis
- 🧪 Possible treatment approaches
- 🛡️ Recommendations designed to minimize damage to the plant

The project combines document retrieval, contextual information processing, and LLM-generated responses.
